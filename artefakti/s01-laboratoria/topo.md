 Сегменти

| Сегмент | Мрежа | VirtualBox адаптер | Роля |
|---|---|---|---|
| WAN | 10.0.2.0/24 | NAT | Изход към интернет през NAT на VirtualBox |
| LAN1 | 10.0.1.0/24 | Internal Network „LAN1“ | Сървърен сегмент (srv) |
| LAN2 | 10.0.3.0/24 | Internal Network „LAN2“ | Резервен/клиентски сегмент |

LAN2 е 10.0.3.0/24, а не 10.0.2.0/24, за да не се застъпва с NAT мрежата на VirtualBox.

## Машини и интерфейси

### gw
| Интерфейс | Сегмент | IP адрес | Маска |
|---|---|---|---|
| enp0s3 | WAN (NAT) | 10.0.2.15 | /24 |
| enp0s8 | LAN1 | 10.0.1.1 | /24 |
| enp0s9 | LAN2 | 10.0.3.1 | /24 |

- hostname: `gw`
- IP forwarding: включен (`net.ipv4.ip_forward=1`)
- default gateway: 10.0.2.2

### srv (сървър)
| Интерфейс | Сегмент | IP адрес | Маска |
|---|---|---|---|
| enp0s3 | LAN1 | 10.0.1.2 | /24 |

- hostname: `srv`
- default gateway: 10.0.1.1 (gw)
- DNS: 8.8.8.8

## Схема

```
        интернет
           |
        [ NAT ]  WAN 10.0.2.0/24
           |
        enp0s3 (10.0.2.15)
      +----- gw -----+
      |              |
 enp0s8          enp0s9
 10.0.1.1        10.0.3.1
      |              |
   LAN1            LAN2
 10.0.1.0/24     10.0.3.0/24
      |
 enp0s3 (10.0.1.2)
     srv
```

## Проверки

- `srv -> gw`: `ping -c3 10.0.1.1`
- `gw -> интернет`: `ping -c3 8.8.8.8`
- `srv -> интернет` (през NAT на gw): `ping -c3 8.8.8.8`
